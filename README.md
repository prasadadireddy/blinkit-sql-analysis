# Blinkit Sales Analysis – SQL Project

##  Project Overview

This project analyzes Blinkit's sales data using **SQL** to understand sales performance, product trends, outlet performance, and customer purchasing patterns.

The main objective is to clean, analyze, and extract meaningful business insights from the dataset using SQL queries.

##  Tools & Technologies

* **SQL Server**
* **SQL**
* **GitHub**
* Dataset: Blinkit Sales Dataset

## Key Analysis Performed

* Analyzed overall sales performance
* Calculated total sales and average sales
* Analyzed sales by product category
* Analyzed sales by outlet type
* Compared outlet sizes and their sales performance
* Analyzed sales based on item visibility
* Analyzed customer ratings
* Identified top-performing products/categories
* Used aggregations and grouping to identify business trends

##  SQL Concepts Used

* SELECT
* WHERE
* GROUP BY
* ORDER BY
* HAVING
* Aggregate Functions (`SUM`, `AVG`, `COUNT`, `MAX`, `MIN`)
* CASE statements
* DISTINCT
* Subqueries
* CTEs
* Window Functions
* Joins
* Data Cleaning and Transformation

## Business Questions

Some of the questions answered through this project include:

1. What is the total sales generated?
2. Which product categories generate the highest sales?
3. Which outlet type performs best?
4. How does outlet size affect sales?
5. Which products have the highest sales?
6. What is the average customer rating?
7. How does item visibility relate to sales?
8. Which outlet locations contribute the most to revenue?

##  Key Insights

The SQL analysis provides insights into:

* High-performing product categories
* Top-performing outlet types
* Sales contribution by outlet size
* Product-level sales performance
* Customer rating patterns
* Overall business performance
